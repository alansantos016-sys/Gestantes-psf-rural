# Gestantes PSF rural
Aplicativo estático local com abas superiores Calendário, Gestantes e Painel. Consultas às terças, limite de 10 registros/dia, DPP estimada DUM + 280 dias, cadastro, histórico, solicitação de exames, carteirinha imprimível e backup AES-GCM/PBKDF2.

Ative GitHub Pages em Settings → Pages → Build and deployment → GitHub Actions. Dados ficam no armazenamento local do navegador e não são enviados ao GitHub. A criptografia do backup não criptografa o armazenamento local. Protótipo para dados fictícios; projeções são administrativas, não protocolo clínico. Dados reais requerem autorização institucional, avaliação de segurança e proteção do aparelho.
